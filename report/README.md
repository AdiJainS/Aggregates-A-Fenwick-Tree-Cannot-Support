# Project report

Build from this folder with `tectonic project-report.tex` (or run `pdflatex` twice). The generated file is `report/project-report.pdf`; copy it to the repository root as `report.pdf` when updating the committed report. The report uses figures in the repository's `results/timing-2026-11-20/` folder, so keep the folder layout intact.

The report describes the current repository and recorded measurements. Confirm the release revisions and application integration before submission.
